# Before awareness · יאוש שלא מדעת

A polished, bounded Argdown demonstration for **Aryeh's meeting with Judd**, based on **Bava Metzia 21b–22b**. The overview contains **22 nodes and 18 relations**. Three episode maps make the argument readable in a meeting.

**Start here:** open [`index.html`](index.html) locally in a browser. It is self-contained, works offline, and includes episode switching, zoom, source notes, Hebrew excerpts, and a four-minute walkthrough. No public site is deployed.

## Scope

Selected episodes, **not every line of the sugya**: the Abaye/Rava dispute and its boundaries (21b:1–4), scattered coins (21b:7), and the decisive river comparison (22b:5–7). Figs/olives and intervening challenges are deliberately omitted. The final river proof is distinct from the earlier exchange on 22a. See the source notes for precise exclusions.

The opening dispute concerns ordinary loss **without an identifying mark**. The marked-object agreement and inaccessible sea/river exception are retained as scope conditions. The latter is a separate scriptural permission, not proof that unconscious yeush is effective.

This maps arguments. It is **not a machine proof, an exhaustive edition, or an executable halakhic decision system**. The Gemara's conclusion is recorded, not generated by a reasoning engine. The map does not issue practical rulings.

## Notation

- Rectangles are claims; hexagons collect reconstructed arguments.
- Green arrows support; red arrows attack. These are dialectical relations in Argdown's **loose mode**, not claims of formal logical entailment.
- **S** = explicit source claim in original English paraphrase; **E** = attributed explanatory expansion; **R** = supplied reconstruction premise or analytical statement.
- All arrows are editorial choices. Disconnected O1–O3 are scope notes, not evidence for a position.
- `+>` means outgoing support, `->` outgoing attack. This project asserts **no undercuts**. In particular, the purse-checking reply attacks C2's factual assumption of unawareness; it does not automatically undercut the inference.
- Episode maps omit arrows to nodes outside the episode. The overview restores C4 → O5 and R6 → O7. The source ledger remains available below every view.

English is used in SVG nodes for readable overview maps. Hebrew/Aramaic is preserved in `.argdown` source comments and in the HTML ledger with isolated right-to-left blocks. This avoids mixed-direction Graphviz line wrapping while preserving inspectable evidence.

## Regenerate and verify

Requirements: **Node.js 22.11 or newer** and npm. Tested with Node 25.9.0. Python 3 is needed only if regenerating authored `.argdown` files from `scripts/author.py`.

```sh
npm ci
npm run build
npm test
```

The build imports the official **@argdown/node 2.0.3**, which uses **@argdown/core 2.0.1** and the official package's Graphviz/WASM renderer. It parses each `.argdown`, builds the argument model, generates DOT and SVG, exports model JSON, and embeds the SVGs into the offline page. No system Graphviz installation is required. `package-lock.json` pins dependencies.

Official CLI **@argdown/cli 2.0.0** is also installed:

```sh
npx argdown 'argdown/*.argdown'
npx argdown map --help
```

For ordinary edits, modify `.argdown` directly and run the build. Keep `sources/model.json` in sync when changing node provenance or relations. For coordinated authoring edits, modify `scripts/author.py`, then run `python3 scripts/author.py`, `npm run build`, and `npm test`. The author script overwrites the four `.argdown` files and the ledger; it is not run implicitly by the build.

The tests check parsing, expected node counts, source-ledger parity, no unintended undercuts, the coins reply's exact target, cross-episode attacks, SVG node counts, source hashes, and local document links. They validate the artifact, not the truth or legal completeness of the reconstruction.

A browser is only needed for viewing or visual QA. Optional local server: `python3 -m http.server 8766 --bind 127.0.0.1`, then open `http://127.0.0.1:8766`. Directly opening `index.html` also works.
